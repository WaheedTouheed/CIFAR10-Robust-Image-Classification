# CIFAR-10 Robust Image Classification

## Project Overview

This project focuses on image classification using the CIFAR-10 dataset and TensorFlow/Keras. The main goal is to train a CNN model using a small training dataset and study how image augmentation affects its performance on clean and corrupted images.

The project is part of Section B of the deep learning assignment.

## Objectives

- Train an image classification model from scratch.
- Use only 500 training images, with 50 images per class.
- Split the selected data into 400 training images and 100 validation images.
- Build a custom CNN containing an Inception-style module.
- Compare different data augmentation strategies.
- Evaluate performance on clean and shifted test images.
- Analyze classification errors using class-wise accuracy and a normalized confusion matrix.
- Study the model's performance on an unseen image corruption.

## Dataset

The project uses the CIFAR-10 dataset, which contains 10 image classes:

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

Each image is an RGB image of size 32 × 32 pixels.

The experiment uses a limited training subset of 500 images. The original CIFAR-10 test set contains 10,000 images.

The dataset can be loaded using Keras:

```python
from tensorflow import keras

(x_all, y_all), (x_clean, y_clean) = (
    keras.datasets.cifar10.load_data()
)
```

## Model Architecture

A custom CNN is used instead of a pretrained model. The network includes convolutional layers, an Inception-style module, pooling, Global Average Pooling, Dropout, and a final Dense layer for 10-class classification.

The model is trained from scratch, following the assignment requirements.

## Data Augmentation Experiments

The notebook investigates the following configurations:

1. No augmentation
2. Geometric augmentation
3. Photometric augmentation
4. Geometric and photometric augmentation
5. Cutout / Random Erasing
6. Mixup with label smoothing
7. Final selected model

These experiments are intended to compare validation accuracy, clean-test accuracy, and shifted-test accuracy.

## Evaluation and Error Analysis

The evaluation includes:

- Training and validation accuracy
- Clean-test accuracy
- Shifted-test accuracy
- Class-wise accuracy
- Normalized confusion matrix
- Misclassified image visualization
- Hidden-corruption evaluation
